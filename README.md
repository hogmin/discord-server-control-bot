This is a discord bot with minimal management functionality. Includes:
* purging messages
* giving roles from message reactions
* temporary voice channels

# Initial Setup

Install requirements
```
python -m pip install -r requirements.txt
```
Create a .env file (either manually or with ```cp .env.example .env```)
Set your ```DISCORD_BOT_TOKEN``` in the .env file

Start bot with ```python bot.py```
